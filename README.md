# 截图填表 · 本地版 0.9.1

Chrome / Edge 扩展。无需账号、大模型、API Key 或 Windows 后台程序。截图、OCR 和字段保存在本机。

## GitHub 下载

在 [Releases](https://github.com/xiaochouwei/screenshot-form-filler/releases) 下载 `screenshot-form-filler-v0.9.1.zip`，解压后在浏览器扩展管理页加载其中包含 `manifest.json` 的“截图填表插件”文件夹。安装包已包含本机 OCR 引擎和模型，无需安装 Node.js。

仓库保存源码、依赖锁文件、测试和验证报告；构建产物与本机缓存不提交到 Git。当前版本完整回归记录见 [0.9.1 验证报告](docs/verification-0.9.1.md)。

## 更新与安装

已经安装：关闭旧侧栏和截图窗口，在 `chrome://extensions/` 或 `edge://extensions/` 找到本插件，点击重新加载，确认版本 **0.9.1**，再刷新来源和目标网页，清除旧版残留的“展开图片架”把手。已更新交付目录中的插件；如果加载的是另一个目录，需要先用新文件替换那个目录。本次不增加权限。旧版截图记录继续保留。原生侧栏开关使用新版浏览器 API，需 Chrome / Edge 142 或更新版本。

首次安装：解压浏览器插件 ZIP，打开扩展管理页面，开启开发者模式，加载包含 `manifest.json` 的“截图填表插件”文件夹，并固定到工具栏。安装后保留该文件夹。企业浏览器策略可能限制安装。

## 默认流程：浏览器右侧栏

1. 在来源网页按 **Alt+Shift+S** 框选完整标签和值；松手后打开浏览器侧栏，保存图片并自动运行本机 OCR。网页不再显示常驻悬浮条或展开把手。
2. 按 **Alt+Shift+F** 开关工作台：关闭时打开，打开时关闭；插件图标也可切换侧栏，侧栏右上角 × 可关闭。关闭不删除本机图片历史。外部截图可在侧栏按 Ctrl+V、点击“粘贴”或导入图片，也可拖入图片文件。这里只接收图片，不持续监听剪贴板。
3. 切换目标网页，在侧栏顶部确认当前网页。未连接时点击“连接当前网站”；设置内也可连接所有网页。选择历史图片、核对字段后，点击底部固定的 **开始填入**。默认自动扫描和匹配；多个表单时选择目标表单后再填。
4. 字段和选项完全同名且唯一、目标为空才填；不明确就跳过，不自动提交。开关和勾选状态需在“填写选项”中显式启用同步。允许增项也在这里，默认关闭。冲突记录显示双方内容，选择来源或确认后才能填写。
5. 保留从已识别预览图拖到目标表单的入口。原生侧栏到网页的拖放受浏览器实现影响，本版没有完成物理鼠标跨侧栏边界的验证；请优先使用“开始填入”。需要独立摆放时点击右上角独立窗口图标。

快捷键由浏览器实际注册；组合键冲突或升级后未分配时，到设置里的“快捷键设置”检查这两个命令。快捷键仅在浏览器获得焦点时有效。

图片架最多保存最近 10 张图片，全部记录合计不超过 3 MiB（含图片与识别数据）；超出时移除较旧记录。当前选中的图片受保护；图片过大时会明确拒绝保存。图片保存为长边最多 2000 像素的 JPEG，初次识别使用导入原图。记录跨同一个浏览器配置中的网站共享，保存在扩展本地，不在来源网站；可删除所选图片或清空。

侧栏与独立窗口共享记录身份和版本，过期编辑会拒绝保存，删除后正在识别的旧结果不会复活图片。切换历史记录保留人工取消，不沿用上一张的匹配结果。页面导航不影响后台正在进行的本机 OCR；浏览器重启打断的任务会标为失败，可在侧栏重试。

侧栏是扩展自身页面，原生粘贴和文件拖入事件不会传给业务网页。不要在业务表单上直接粘贴或拖入系统图片文件，那可能触发网站自己的上传功能。

来源可为任何清晰的受支持图片，目标限定浏览器网页表单。插件不能一键框选浏览器之外的桌面，外部截图需用系统截图后粘贴。没有来源网页时，纯像素无法可靠区分所有提示词和实际值，也不自动推测勾选状态。不会提交表单，也不保证任意自定义组件都支持。

## 0.8.0 通用扫描与来源核对

本版按控件语义、标签关系、布局证据和适配器处理页面，不以某个网站的字段名或地址编写匹配规则。处理流程为：本机 OCR → 可选来源网页证据校对 → 目标控件清单 → 同名唯一匹配 → 写入并读回。外部图片仍可以独立使用。

新识别记录默认勾选“参与填写”，包括多选、组合字段和待核对记录。勾选只决定是否参与，不代表内容已经核对：高可信或有一致来源证据的记录可以继续匹配；低可信、结构不明确和真实冲突保留“待核对”。点击“确认当前值”“采用截图值”或“采用网页原值”后才可继续。修改名称、类型或内容会重新变为待核对，不会取消参与；单纯重新勾选不能代替内容核对。手动取消不会被采用来源值、自动多选校验或恢复记录勾回。

网页框选时，对受支持样式的原生文本域记录实际宽度、字体和 CSS 下的自动折行位置。仅当 OCR 与网页原值的差异完全位于这些折行位置，才校对为一致，并保留原 OCR 文字。真实换行、字符、空格、标点或截断差异仍需选择来源值；不会全局去空白或默认采用网页。旧图片没有本次采集的布局证据时保留原状态，重新截图才能取得新证据；纯图片没有网页布局证据。

扫描先等待控件清单短暂稳定，最多约 1.5 秒；仍在变化或带有加载标记时会说明，并阻止基于该次扫描填写。扫描结果区分当前表单与全页字段数，展示已适配、未适配、无标签、组合子项与原始候选节点，以及未扫描的内嵌页面。按钮不计为数据字段；可发现但尚不能可靠写入的语义控件列出原因。报告仅描述已渲染且可访问的结构，不代表虚拟列表、未展开区域或内嵌页面已扫描。

## 下拉框等待

0.7.2 改善自定义下拉框的等待：展开面板最多等待约 2.5 秒，完整目标选项另等待最多约 3 秒，检查可观察到的选项稳定状态和 `aria-busy` 加载标记。不会因先返回了部分选项而马上判定失败，也不会反复点击展开按钮。等待期间控件禁用、只读、隐藏、页面跳转或归属变化立即停止；字段和选项完全匹配规则不变。已展开且有明确关联的选项面板直接使用；已展开但无法确认归属时提示先收起再试。无选项、展开超时、多个面板及选项加载超时会分别说明。超过等待上限、没有可靠归属关系或特殊触发方式的组件仍可能跳过。

## 动态增项与多选默认勾选

0.7.1 的图片架和核对窗口新增“允许增项”，默认关闭，每个新页面或新窗口需自行开启。仅当目标缺少该字段、来源组合字段已确认、按钮名称为“添加/新增/增加 + 完整字段名”或“Add + 完整字段名”，或者按钮通过 `aria-controls` 唯一关联同名区域时，才尝试调用网页已有的添加功能。按钮必须属于已选择的表单，且为明确的非提交按钮或结构简单的按钮角色控件。

本版支持补建有明确 key/value 子项的组合行，可包含需要显式同步的勾选状态；不会凭空向业务页面注入表单组件。一次最多新增 5 个不同名称的行，每个入口只点击一次，等待并确认唯一、完整、稳定的新行后才填。重名、已有同名行、只读、禁用、提交/重置控件、弹窗或跳转入口、创建超时和结构不符时跳过或停止。失败时可能已留下空白新行，需要人工检查；不尝试自动删除或回滚。网站的添加动作也可能触发自身自动保存。

多选 OCR 区分“仅多行/分散布局待核对”和“用户取消”。已参与的清晰来源字段与目标字段完全同名，且所有值唯一、完整地对应可用选项时，可以自动核对为可填写。尚未加载的选项只会在明确的填写操作中展开核对，全部验证通过后才选择。手动取消、编辑后的待核对内容、低可信、来源冲突、缺项和歧义不会被自动批准。旧截图保留其原参与状态；重新截图/识别后使用新的默认规则。

## 可选独立图片窗口

侧栏右上角可打开独立图片窗口。旧版明确选过“独立图片窗口”的设置继续保留。以下为保留的高级流程；默认侧栏不需要这些手动步骤。

1. 打开来源网页与目标网页。一块屏幕即可使用；有两块屏幕时也可分开摆放。两个网页必须属于同一个浏览器、同一个用户配置。
2. 在有内容的来源网页按 **Alt+Shift+S**，框选完整的字段名称和对应控件。松开鼠标后自动出现独立截图小窗口。
3. 插件对截图做本机 OCR，以图片文字作为主要来源；能读取来源网页时，用选区内字段的原值、类型和明确状态辅助核对。结果一致时标记“截图 · 网页校对”，冲突时保留双方内容并标为待核对，可点击“采用截图值”或“采用网页原值”。没有图片对应项的网页字段单独标记“网页辅助”。网页空控件的提示区域和明确状态图标不作为 OCR 文字值。新记录默认参与，不确定项核对后才能填。
4. 首次使用时，点击小窗口的**“连接所有网页”**，在浏览器弹窗中同意一次授权。也可以在接收网页列表选定目标，只点击旁边的链条图标授权该网站。没有连接时截图不能拖出，窗口会显示原因。
5. 把小窗口里的**截图缩略图**拖到目标表单内部。落点表单会高亮，松开后只填写该表单内完全同名、唯一、受支持的字段。小窗口显示写入和跳过数量，展开“字段与填写结果”可查看原因。跨窗口拖拽不成功时，先点一下目标网页，再回小窗口点击“扫描当前页”并选择表单，最后点击底部固定的**“开始填入”**。

接收网页下拉框只用于确认网站连接状态，不决定“扫描当前页”或“开始填入”的目标。扫描当前页读取最近操作的普通浏览器窗口中的活动标签；扫描后，匹配预览和开始填入锁定该标签，切换其他窗口不会悄悄改写目标。拖拽实际写入哪里由鼠标落点决定。存在多个表单时，必须拖进指定表单内。仅填写一项时，展开字段列表，拖该行左侧六点图标到同名控件。

独立窗口是普通浏览器扩展窗口，可以移动到另一块屏幕，暂不支持始终置顶。不要把系统截图文件直接拖到业务网页，那可能触发网页自己的文件上传；先拖入图片架，再从缩略图拖向表单。

按 Esc 或再次按快捷键取消框选；误点或不足 8 像素的选区可重新选择。两分钟未完成、切换标签、滚动或改变页面尺寸会取消框选。同一文档内自动改变路由不会使框选失效；换到另一网站或重新加载文档后需重新框选。框选凭证保存在浏览器扩展会话中，后台进程重启不会使正在进行的框选失效；插件本身重新加载时仍需刷新网页。只截取当前可见网页，不含浏览器工具栏、其他 Windows 程序或屏幕外内容。像素比例按实际截图换算，触屏捏合缩放暂不支持。

快捷键仅在浏览器获得焦点时有效，不是 Windows 全局热键。无反应时，到 `chrome://extensions/shortcuts` 或 `edge://extensions/shortcuts` 检查“框选当前网页并自动识别截图”的绑定，必要时更换冲突组合。插件图标出现 `!` 时，悬停可查看截图失败原因。

0.6.4 增加字符计数排除：来源网页中具有明确计数结构、且分子和分母与真实值长度及 maxlength 一致的提示，会在 OCR 前遮罩；纯图片中，仅对框内最右侧、与正文有明显间距、且计数与正文长度一致的尾部计数排除。正文里的 `11/256` 等内容保留。无法确定的仍需核对，截图与网页不一致时可点“采用网页原值”。已经混入来源真实值的计数无法自动区分，需先修正来源再截图。

拖拽以实际落点网页为准，有其他已连接网页时，接收列表选中的未连接网页不再禁用图片拖拽。自定义拖拽格式丢失但备用文本标记保留时，仍由后台核对一次性标记、接收文档与有效期后填写。没有已连接网页或未勾选字段时，按下图片会提示具体原因。拖的是插件中的截图缩略图，不是系统截图文件。

0.6.5 增强网页框选时的提示过滤：原生与组合字段的空输入提示、ARIA 关联说明、常见表单帮助或校验说明、页面 note/tooltip/alert，以及有明确标签和控件的局部字段容器中的非控件文字，在 OCR 前排除。字段标签、输入值和已选选项保留；原生标签内部明确标注的帮助内容不参与字段名。未按业务字段名、网址或提示句编写黑名单。纯图片中，远处说明不再只因间距大就成为补充字段值，还需符合已有控件的列结构。没有网页结构的图片不能保证区分所有占位提示和真实值；与真实输入视觉相同的内容无法凭像素可靠判断。已经写进实际输入值的说明文字需先清理。

## 下拉、单选、勾选与按钮

| 控件 | 处理规则 |
| --- | --- |
| 文本、文本域、URL、电话、邮箱、数字 | 字段同名且目标为空才填，数字还校验格式和约束 |
| key / value 组合字段 | 目标须有明确子项标识和唯一外层标签；逐项校验、写入并读回。同步组内状态时，已有文字须逐字相同才可保留文字继续同步；不同文字仍整组跳过 |
| 组件内的数字输入 | 带明确数字语义或 input-number 结构的输入按数字校验、写入并读回 |
| 原生下拉 | 选项文字完全一致、唯一且可用；目标必须为空 |
| 原生多选 | 接受选项数组，或依据目标完整选项唯一拆分的截图文字；目标必须为空，全部选项精确匹配才开始 |
| 自定义下拉、多选 | 支持结构明确的 ARIA、iView、Element、Ant Design 常见结构；需要明确的触发控件、选项归属和可读回状态 |
| 单选组 | 支持明确的 fieldset 或 radiogroup 分组；无选择时可填，替换已有选择需启用状态同步 |
| 复选框、开关 | 必须主动勾选“同步开关 / 勾选状态”，才同步明确的开/关、选中/未选中状态 |
| 按钮式开关 | 仅识别具有明确开关语义和状态的控件，不根据按钮文字猜动作 |
| 保存、提交、新增、删除等操作按钮 | 不自动点击 |

状态同步默认关闭，会记住你的设置。启用后可能将目标从开启改为关闭、从选中改为未选中。文本和下拉的已有内容仍不覆盖。不能确定状态、标签冲突、三态勾选、多个候选弹层或重复选项时跳过。

纯截图 OCR 提取文字、位置和相邻输入框结构，不推测勾选状态，也不推测未展开下拉里的隐藏选项。需要同步开关、复选或多选时，可访问的来源网页提供明确状态作为辅助。来源不是网页或未识别出状态时，可展开字段列表，将“字段类型”改为“开关 / 勾选”并选择状态，或改为“多选值”逐行输入选项，然后点击“确认当前值”；开关写入还需启用“同步开关 / 勾选状态”。不能保证任意图片的开关、多选都自动还原。

支持截图中一行多个已选标签的填写：字段可以保持“文字 / 自动匹配”；内容待核对时先点击“确认当前值”，再拖拽或开始填入。目标若是多选，按其完整选项文字拆分；尚未加载选项的受支持下拉，会先展开并读取选项，再核对全部值。选项自身含空格时按完整名称处理，不按单个词切分；重名、禁用、缺字、多种组合或无法读到选项时跳过。不会按逗号猜测多个选项，也不忽略大小写、内部空格或标点差异。成功后列表显示为“多选值”，每项一行并保存。多选目标已有选择时仍不覆盖；“同步开关 / 勾选状态”不是多选填入的开关。

纯截图中同一标签下的两个相邻输入框会显示为可编辑组合，暂按左 key、右 value 展示，必须核对子项后点击“确认当前值”。若本次截图的来源 DOM 同时证明子项名称和值一致，可自动校对并补充明确的组内勾选状态。目标中的 key/value 依据 `name`、`data-field`、ARIA 或明确的 key/value 占位语义识别；普通未命名双输入框仍跳过。字段本身的名称匹配不使用 placeholder。

## 严格匹配与边界

- 名称只去掉首尾空白；内部空格、大小写、标点和单位必须一致。“名称”不匹配“项目名称”，不使用近义词或大模型猜测。
- 来源重名、目标表单内重名、标签不明确、已有内容时跳过。`http://`、空格和默认值都算已有内容；状态同步是明确启用的例外。
- 优先使用原生 label、ARIA 标签，其次使用最近单控件容器中的唯一结构标签；不使用 placeholder 或普通说明文字猜字段。
- 如果表单标签明确指向自定义控件内部输入框，会归给该控件。组合字段需要明确子项语义；一个标签对应多个无独立名称的输入框时仍跳过，单个文字值不会自动拆分给多个目标。
- 网页原值只读取实际控件和标签文字完整包含在选区内的来源字段，且绑定本次截图。标签容器、勾选标签与组合字段外层的空白不计入证据边界。截图 OCR 每次都会运行。网页来源的空输入框、空下拉提示区域由 DOM 位置排除；只有图片时，OCR 会跳过“请输入…”和“请选择…”等常见提示，其他不确定文字仍需人工核对。截图与网页冲突时保留双方证据，不静默替换。网页里的空白控件没有可复制的值，不会作为来源行；目标空白控件由扫描单独读取。
- 填写前重新核对页面和控件，填写后读回验证。网页不保留写入值、业务校验失败或下拉归属变化时报告失败；多个控件或多选写入不是事务，发生中途失败时可能已写入一部分，请查看结果。
- 支持开放 Shadow DOM；不支持 iframe 内表单、封闭 Shadow DOM、Canvas、富文本、日期、级联、树选择，以及结构不明确的自定义控件。不能保证任意网站全部适配。
- 隐藏、透明、零尺寸、只读、禁用、密码、验证码和标准信用卡等敏感字段不自动填写。最多 200 个来源字段，页面超过 2000 个控件时拒绝扫描。
- ARIA 标签引用缺失或为空时不采用残余文字匹配。普通输入的父容器标记禁用，或自定义下拉内部输入禁用时不写入。多选每次点击前核对可写状态和已选列表，发生变化即停止后续选择；已经触发的网页联动无法保证回滚。
- 浏览器内部页面、扩展商店等受保护页面无法连接。不同浏览器、不同用户配置、Windows 原生程序之间的自动填表不在本版范围内。

## 图片导入、详细侧栏与保存

来源是其他 Windows 程序时，可以用 Win+Shift+S 截图，再打开插件点“粘贴截图”，或 Ctrl+V、导入/拖入图片文件。支持 PNG/JPG/WebP/BMP，最大 12 MB、1600 万像素。不会持续监听或自动读取系统剪贴板。

图片导入后自动 OCR，使用本机 PaddleOCR v4 检测和逐区域识别，保留文字坐标；中英文混排标签会局部复核空格，保留 Tesseract 作为本地备用引擎。中文小字、浅灰文字、IP 和 URL 标点仍可能识别错误。新记录默认参与不代表已人工核对；低可信度、多块值、结构不确定或来源冲突的记录可能需要核对。修改名称或值后需要点击“确认当前值”；重新识别按新结果重新判断。旧记录的取消状态保持不变。

浏览器侧栏是默认工作台，保留扫描、匹配预览、一键填入，整页截图收在设置内。整页截图要求来源标签是其窗口内的活动标签。

图片和字段保存在当前浏览器配置的扩展本地存储中，不保存在来源网站；换网站、关闭窗口或重启后仍可恢复。垃圾桶删除当前图片；设置里的“清空图片历史”删除全部记录。

插件不自动提交表单；网页自身可能在输入或选择时自动保存或发送请求。请检查填写结果后自行提交。

## 权限与本地处理

安装权限为 `activeTab,scripting,sidePanel,tabs,storage,clipboardRead,offscreen`。HTTP/HTTPS/file 网站权限按需要申请，不在安装时取得全部网站访问权。可以授权当前网站或在设置中连接所有 HTTP/HTTPS 网站。授权后只加载无界面的接收器；普通扫描返回标签、约束、选项和占用状态，截图时才提取受支持的来源字段原值。

拖放数据仅携带一次性标记（自定义类型及纯文本备用副本），不携带截图或字段值；后台校验实际接收标签、URL、文档身份和 60 秒有效期，使用后即失效。只有真实浏览器拖放事件才处理。若标记丢失、目标页未连接或页面已变化，小窗口分别提示原因。

OCR 引擎、中英文模型、WASM 随包附带，运行不访问云端；截图和字段不上传、不同步。新 OCR 在无扩展 API 的隔离页中运行，仅通过专用消息端口传递图像与结果；识别结束或取消即释放隔离页。普通扩展页的脚本策略保持原有约束。云端接口继续保留为禁用状态，没有大模型调用。本地文件需在扩展详情开启“允许访问文件网址”。
