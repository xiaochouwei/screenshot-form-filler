# 0.6.2 排查与验证

验证日期：2026-10-28。环境：Windows、本机 Edge、Node.js 22、Playwright。运行命令：`npm run test:regression`。

## 发现并修复

| 遗漏 | 原有行为 | 修复与复现验证 |
| --- | --- | --- |
| 下拉选项异步加载 | 仅自动拆分文字的多选会等待；单选、明确多选数组可能过早判断缺少选项 | 对初始为空的自定义下拉统一等待；有尺寸但尚未填入选项的弹层延迟 180 ms 后仍可正确填写 |
| 多选中途状态变化 | 第一项触发禁用、只读、隐藏或额外选择后，仍可能点击第二项 | 每次点击前检查可写状态和已选列表；四个故障注入用例均只点击第一项后停止 |
| 标签引用不完整 | ARIA 引用缺失、空标签可能被拼成残缺名称，或退回其他名称 | 引用必须完整且各部分非空，否则拒绝作为匹配标签；完整引用仍正常读取 |
| 禁用状态遗漏 | 文本框父容器的 ARIA 禁用、自定义下拉内部原生输入禁用未全面检查 | 两个用例均不填写；被禁用的下拉不会打开选项 |
| 大截图保存后的遮罩位置 | 图片缩小为长边 2000 px，排除提示词的坐标仍保留原尺寸 | 按实际横纵尺寸缩放遮罩；2400 px 截图保存、关闭恢复、再次离线识别后坐标保持一致 |

这些回归用例均先复现旧逻辑失败，再验证修复通过。旧版本截图没有遮罩坐标系标记时保留图片和字段，放弃不能确认位置的旧遮罩。

## 验证结果

- 构建通过；42 个单元测试通过。
- 22 组浏览器及扩展检查通过，包括新增的 9 个控件边界用例和大截图恢复检查。
- 覆盖字段标签、常见提示词排除、原生/ARIA/iView/Element/Ant Design 常见控件结构、文本、数字、单选、多选、复选、开关及 key/value 组合。
- 覆盖无来源 DOM 的截图、本机 OCR、来源冲突核对、默认勾选、保存恢复、一键填入、单字段与整张截图拖拽、多表单范围和已有内容保护。
- 覆盖框选取消、缩放、命令入口、权限拒绝、页面变化、拖拽凭证重复使用、读回校验及清空保存。
- 离线 OCR 和端到端用例检查了无远程请求；测试表单未触发提交。

## 范围与剩余限制

- 控件适配测试使用可控的原生和常见组件 DOM 结构，并非所有框架版本、全部网站的实测。未登录或操作实际业务系统。
- 不支持 iframe 内表单、封闭 Shadow DOM、Canvas 表单、富文本、日期、级联和树选择。远程搜索或虚拟滚动下拉未做通用适配；读不到全部需要的选项时不能填写。
- OCR 仍可能识别错字、数字或标点；低可信度或结构不明确的来源需核对。纯图片无法可靠推断所有开关和勾选状态。
- 多字段与多选填写不具备事务回滚；网页中途禁用、隐藏或联动时会停止，但已经写入的部分需要人工检查。
- 跨窗口拖放通过真实浏览器拖拽起始事件与 CDP 受信任落点事件验证，未验证 Windows 物理鼠标的完整轨迹。快捷键通过命令 API 钩子验证，未模拟系统级组合键。原生授权弹窗仍需安装环境现场确认。
- 所有字段和选项继续要求完整同名、唯一且可用，不增加模糊匹配、云端处理或大模型调用。
