# 0.7.0 浏览器图片架验证

## 本次范围

仅浏览器扩展，不安装 Windows 客户端。来源为网页框选、剪贴板图片或本地图片；目标为浏览器中受支持的表单。OCR 在本机运行，来源网页仅提供辅助证据，不依赖具体业务网址、字段名或提示词。

默认流程为框选后自动识别并保存至网页顶部图片架。在目标网页展开同一图片架，将已识别缩略图拖到表单，或点击“开始填入”。详细字段核对保留为可选独立窗口。原生粘贴和图片文件拖入使用扩展自身的“图片接收区”，不将事件交给业务网页。

## 保留的填写约束

- 字段名称、选项必须完全匹配且唯一，来源不确定则跳过。
- 不覆盖已填写文字，不自动提交，不点击业务动作按钮。
- 单选、多选、下拉和状态控件复用原有通用扫描与适配器，填写后读回校验。
- 勾选、开关等状态同步需显式开启；没有可靠状态证据的独立图片不推测状态。
- 多表单按实际拖拽落点选择；按钮填写要求选择目标表单。

## 新增验证

- 历史记录的身份、版本、增删选取、大小和数量限制、旧记录迁移；迟到的 OCR 结果不能复活已删除记录。
- 网页内完整浏览器鼠标轨迹：缩略图按下、移动、松开到真实目标表单。目标 drop 未通过脚本派发。封闭 Shadow DOM 的交付 bundle 另用坐标验证。
- 来源框选到隐藏扩展页面 OCR，再到图片架保存；独立 PNG 无来源 DOM 辅助也能识别并填写。
- 离线 OCR 与零云端请求，页面刷新后的历史恢复、删除与识别并发。
- 在扩展接收区构造带图片文件、`composed:true` 的粘贴事件，验证它不进入宿主网页捕获监听器；该项验证事件隔离，不等同 Windows 实物剪贴板按键测试。
- 严格页面 CSP 下 canvas 缩略图非空与按钮填写；网站禁止嵌入接收区时仍有导入按钮和独立窗口入口。
- 权限撤销移除旧图片架并拒绝扫描；等待中的填写停止。单元测试模拟 MV3 后台重启后撤销权限，覆盖无接收器缓存时的清理、旧拖拽失效与历史访问拒绝。
- 核对窗口在预览期间删除记录后，填写被拒绝；记录身份和版本也用于旧窗口拖拽。
- 宽屏与 390 像素视口截图检查，没有横向溢出。

## 验证边界

2026-10-29 最终执行 `npm run test:regression`，退出码为 0：构建、48 个单元测试和 30 组浏览器/扩展检查全部通过。浏览器为本机 Microsoft Edge 156.0.4314.50。字符计数图片用例在生成来源截图前隐藏新增图片架，避免把插件浮条作为表单证据混入；生产框选与核对窗口截图也会隐藏图片架。

交付包含直接加载目录、浏览器插件 ZIP 与源码 ZIP。两个插件目录的全部 62 个构建文件按 SHA-256 对比一致，ZIP 内文件也逐项校验。插件版本为 0.7.0。

浏览器自动化使用本机 Edge 与构造的通用测试页面，不代表已现场覆盖用户的全部业务系统。网站权限原生弹窗仍需用户实际授权。后台重启后的撤权用受控单元测试模拟，不冒充操作系统或浏览器设置界面的人工实测。

旧跨窗口拖拽测试有真实源 dragstart，但目标通过 CDP 派发 drop，不能证明 Windows 物理鼠标跨窗口或跨屏轨迹。网页内图片架的完整拖拽已采用浏览器鼠标轨迹验证，一块屏幕即可使用。

浏览器不允许扩展框选其他桌面应用，需系统截图后导入。特殊 Canvas 表单、封闭 Shadow DOM、跨域内嵌表单及未知自定义控件不保证支持。纯图片中提示词与真实值视觉相同时无法保证自动区分，仍需核对。不发布到扩展商店，本次交付为本地加载版本。
