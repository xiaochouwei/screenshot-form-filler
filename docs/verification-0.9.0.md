# 0.9.0 浏览器侧栏工作台验证

## 目的与复盘

用户认可现有功能，要求 UI 专家优化操作布局，并明确选择浏览器右侧栏。产品保持任意来源截图、本机 OCR 为主、来源网页辅助、目标限浏览器表单；字段及选项精确唯一匹配，不确定则跳过，不自动提交。

旧界面的问题主要是操作入口都挤在业务网页顶部，收起后也有常驻把手；图片、连接、核对与结果分散，不只是配色问题。本次将工作台移至浏览器原生侧栏，保留稳定的识别和写入逻辑，不引入业务页面特例。

## 改动

- 插件图标默认打开原生侧栏；Alt+Shift+F 召唤工作台，Alt+Shift+S 继续框选网页。浏览器实际注册的快捷键可从设置检查。
- 已授权网页仅注入无界面的接收器。网页加载、切换、历史变化和默认截图均不自动创建悬浮图片架。
- 框选先在原视口裁剪并采集来源证据，再在真实松手手势中申请打开侧栏；本机后台 OCR 更新共享图片历史。避免先打开侧栏改变来源页面宽度。
- 图片历史、预览、核对、目标选择与结果集中于单一滚动区，底部固定填写按钮。设置、整页截图、快捷键配置和清空历史按需展开。
- 未连接时直接显示“连接当前网站”。已识别记录、人工取消和来源核对规则保留；切换图片会清除上一张的匹配结果。
- UI 专家检查实际集成状态，修复短窗口预览过高、重复标题与列头换行。错误信息带入可视区，匹配预览和实际填写结果分别命名。
- 最终审查复现同标签页跳转后页头仍显示旧标题和连接的问题，新增导航回归，再按活动页 URL、加载和标题事件更新网站信息与接收状态。
- 复用既有“预览期间删除来源图片”检查，确认写入被阻止，并修复空记录恢复覆盖“截图已变化”错误提示的问题。旧接收列表测试先展开设置后再操作，匹配目标仍独立于接收列表。
- 不增加权限、依赖、客户端或云端服务。旧版明确选择的独立窗口模式保留，侧栏也可手动打开独立窗口。

## 验证项目

- 新增 2 个后台单元检查：无常驻界面、原生侧栏图标行为、快捷键同步打开时序、框选不预先改变视口、默认后台 OCR 入口和非授权消息拒绝。
- 新增 workspace-browser 实际加载扩展检查：真实鼠标框选、本机 OCR、实际 SIDE_PANEL 上下文创建、共享历史、手动取消恢复、历史间结果隔离、按钮精确填写、不提交、处理/错误/空状态。
- 280、360、400、440 像素宽与 570 像素高的工作台检查主区域滚动、横向溢出和固定页脚边界，并保存截图。UI 专家另检查 520 像素高窗口。
- 原有网页图片架测试显式请求兼容界面，不将旧版自动悬浮行为重新加入产品。原有权限、截图、OCR、拖拽协议、多选、状态、动态增项和扫描用例继续执行。

## 验证结果

2026-10-30 在 Microsoft Edge 156.0.4314.50 上运行 `npm run test:regression`：构建、58 个单元测试通过，35 组浏览器/扩展检查中 34 组直接通过。structured-image 的旧断言要求 checkbox 的 CSS gridColumnStart 必须等于 2；新版自动网格下该计算属性为 auto，实际仍在第二列。将断言改为检查控件在标签右侧、位于组合行内且不重叠后，专项重跑退出码 0。此后仅修改测试断言，生产代码没有变化，35 组检查均已分别验证通过。

完整运行的原始日志保留了这处旧断言失败及退出码 1；补测日志单独交付为 `0.9.0-组合字段布局补测.txt`，没有将原始失败隐藏为一次完整通过。此前发现的页面导航状态和删除来源后错误提示覆盖问题，均在修复后的这次完整运行中通过。

两个现有插件目录均已同步为 0.9.0，各 62 个文件逐项 SHA-256 与最终 dist 一致；交付源码的 103 个文件与工作目录对应文件一致。浏览器插件 ZIP 的 63 个文件、源码 ZIP 的 103 个文件均逐项校验了文件数和 SHA-256。manifest 版本、7 项原有权限及无必需全站权限的状态检查通过。本报告更新后再次同步源码 ZIP 并复核。

## 实测边界

实际框选鼠标松手后，浏览器确实创建 SIDE_PANEL 上下文；快捷键注册与调用时序有自动检查，但自动化命令钩子不等同于操作系统物理按键。

界面截图和大部分交互通过相同生产 panel.html 在扩展页面中运行，并注入独立构造的记录检查状态，不是对用户业务系统截图的识别结果。授权测试副本预设网站权限或检查拒绝路径，未自动接受用户的原生权限弹窗。

原生侧栏到业务网页的物理拖拽没有完成验证。保留预览图拖拽协议和独立窗口入口，优先使用“开始填入”。旧版同页图片架真实指针拖拽仍有回归；CDP 派发跨窗口 drop 只能验证协议，不能证明物理鼠标跨浏览器界面边界。

浏览器侧栏打开会占据浏览器宽度，可能使网站自身响应式重排。框选先裁剪后打开；不保证所有网站、iframe、封闭 Shadow DOM 或未渲染自定义组件均可读取写入。
